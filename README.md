**🛡️ ПОЧЕМУ АНТИВИРУСЫ "РУГАЮТСЯ" НА EXTREME TWEAKER? ПОЛНОЕ РАЗЪЯСНЕНИЕ**

Друзья, мы видим вопросы о том, почему некоторые системы безопасности отмечают наш твикер. Давайте честно разберёмся, что происходит и почему это НОРМАЛЬНО для такого типа софта!

**🤔 ПОЧЕМУ БРАУЗЕРЫ И АНТИВИРУСЫ НЕ ДОВЕРЯЮТ?**

1. **НЕТ СЕРТИФИКАТА** — Мы не можем позволить дорогостоящий EV-сертификат (стоимость ~$500 в год), поэтому Windows и браузеры видят "неизвестного издателя"

2. **МАЛО СКАЧИВАНИЙ** — Новый софт без репутации автоматически вызывает подозрения у систем безопасности

3. **PYINSTALLER** — Мы используем стандартный инструмент сборки Python в EXE, который:
   - Распаковывает себя во временные каталоги (temp)
   - Использует Python-интерпретатор (часто используется вредоносами)
   - Создает временные файлы при запуске

**🔧 ЧТО НА САМОМ ДЕЛЕ ДЕЛАЕТ EXTREME TWEAKER?**

Давайте посмотрим на результаты анализа песочницы:

**📁 ФАЙЛОВЫЕ ОПЕРАЦИИ:**
- Работает в `C:\Apps\Extreme\` — это наша папка установки
- Создает BAT-файлы с русскими названиями (в кодировке UTF-8)
- Удаляет временные файлы Microsoft и службы телеметрии
- Очищает кэши и логи системы

**⚙️ РЕЕСТР И СИСТЕМА:**
- Модифицирует настройки `HKEY_CURRENT_USER\Control Panel\Desktop` (визуальные эффекты)
- Настраивает `HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows` (оптимизация)
- Работает с планировщиком задач и службами

**🔄 ПРОЦЕССЫ:**
- Запускает `cmd.exe` для выполнения скриптов
- Использует `sc.exe` для управления службами Windows
- Останавливает ненужные процессы (телеметрия, диагностика)

**🎯 ПОЧЕМУ ЭТО ВЫГЛЯДИТ "ПОДОЗРИТЕЛЬНО"?**

Вот что видят системы анализа (и это НОРМАЛЬНО для оптимизатора):

1. **"Скрытие артефактов"** — мы отключаем телеметрию
2. **"Маскировка"** — используем стандартные пути Windows
3. **"Инъекция процессов"** — внедряем настройки в системные процессы
4. **"Уклонение от защиты"** — отключаем некоторые службы безопасности
5. **"Обфускация"** — русские имена файлов в кодировке UTF-8
