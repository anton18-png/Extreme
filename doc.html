Введение

Extreme Tweaker - это мощная программа для глубокой оптимизации и настройки операционной системы Windows. Программа предоставляет пользователям широкий набор инструментов для улучшения производительности, приватности, безопасности и кастомизации системы.

📌

Интерфейс и режимы работы

💻

Минималистичный режим (Lite)

При первом запуске программа открывается в минималистичном режиме с:

  • Центрированным заголовком "Extreme Tweaker Lite"
  • Вкладками с чекбоксами из специального набора tabs_mini:
    • Отключение телеметрии: Твики для полного отключения телеметрии Windows
    • Игровые настройки: Оптимизация для игр и производительности
    • Экстремальная оптимизация: Агрессивные настройки для максимальной производительности
    • Драйверы и остальное: Настройки драйверов и компонентов системы
    • Очистка: Инструменты очистки системы
    • Электропитание: Схемы электропитания для оптимизации
  • Кнопкой настроек в правом нижнем углу
  • Клик по заголовку открывает полную версию
  • Все функции полноценных вкладок доступны в минималистичном режиме
🖥️

Полный режим

Полный режим включает:

  • Верхнюю панель с кнопками быстрого доступа
  • Боковое меню (сайдбар) с навигацией
  • Основную область с вкладками
  • Поиск по твикам
  • Фильтрацию чекбоксов
👶

Режим новичка

Специальный безопасный режим для начинающих пользователей:

  • Показывает только проверенные и безопасные твики

  • Упрощенный интерфейс настроек

  • Рекомендации по использованию
👨‍💻

Режимы отображения чекбоксов

Программа поддерживает 4 режима отображения чекбоксов:

📋

1. All Tweaker (regular)

  • Стандартный режим отображения
  • Обычные чекбоксы в сетке
  • Компактное отображение
  • Подходит для просмотра большого количества твиков
🔲

2. Hone (rectangle)

  • Чекбоксы в виде прямоугольных карточек
  • Более наглядное отображение
  • Удобно для выбора конкретных твиков
  • Занимает больше места
📄

3. BoosterX (expandable)

  • Широкие прямоугольные чекбоксы на всю ширину
  • Раскрывающееся описание по клику на кнопку "➕"
  • Кнопка "▶ Запустить" для быстрого запуска
  • Удобно для детального изучения твиков
💎

4. Sapphire (sapphire)

  • Аналогично BoosterX, но в два столбца
  • Более компактное отображение
  • Сохраняет все функции BoosterX
  • Оптимально для широких экранов

Смена режима: Настройки → Дополнительно → Режим отображения чекбоксов

⚠️ Рекомендуемые требования для оптимальной работы

ВАЖНО: Требования к системе безопасности

Для корректной работы Extreme Tweaker настоятельно рекомендуется использовать специальные сборки Windows, где:

  1. Windows Defender отключен или удален
    • Defender может блокировать выполнение скриптов
    • Может конфликтовать с твиками, которые отключают телеметрию
    • Может помечать программу как подозрительную
  2. SmartScreen отключен
    • SmartScreen может блокировать запуск программы
    • Может мешать применению твиков
    • Рекомендуется отключить как в системе, так и в браузере
  3. Антивирус отключен или добавлен в исключения
    • Многие антивирусы могут блокировать системные изменения
    • Рекомендуется добавить папку с программой в исключения
  4. Рекомендуемые сборки Windows:
    • ReviOS
    • AtlasOS
    • MakuOS
    • SapphireOS
    • И другие оптимизированные сборки с отключенным Defender
Почему это важно:
  • Программа выполняет глубокие системные изменения
  • Антивирусы и защитники могут блокировать эти изменения
  • Это может привести к зависаниям и конфликтам
  • Если твикер долго не отвечает, возможно, происходит конфликт с защитными системами
Что делать при зависаниях:
  • Если программа зависла при применении твиков, это может быть конфликт с антивирусом или SmartScreen
  • Рекомендуется закрыть программу и добавить её в исключения
  • Перезапустить программу и повторить попытку

Почему антивирусы "ругаются" на Extreme Tweaker?

🛡 ПОЛНОЕ РАЗЪЯСНЕНИЕ

Друзья, мы видим вопросы о том, почему некоторые системы безопасности отмечают наш твикер. Давайте честно разберёмся, что происходит и почему это НОРМАЛЬНО для такого типа софта!

🚬 Интересная ситуация с "вирусами" в последнее время

Заметили, как браузеры стали агрессивно блокировать скачивание файлов? Мол, "опасно", "подозрительно", "вирус". Особенно достается твикерам и оптимизаторам.

Возьмем, к примеру, наш Extreme Tweaker 🤔 Браузеры нервничают, антивирусы сигналят... А по факту — весь код открыт на GitHub, можно проверить каждую строчку. Но нет, система "знает лучше".

💸 ГЛАВНЫЙ "СЕКРЕТ" АНТИВИРУСОВ

А вот главный прикол: 90% этих "обнаружений" — просто потому что у .exe файлов нет цифровой подписи.

И угадайте, сколько стоит эта подпись? Правильно, деньги 💸 И не малые — 300-500$ в год!
